# 해외 동일 성분 제품 탭 설계

## 1. 목적과 범위

`REQ-F-015`는 현재 상세 조회 중인 국내 의약품과 **같은 주성분을 가진 미국 유통 제품**을 상세 화면의 별도 탭에서 조회하는 기능이다. 이 기능은 해외 의약품의 구매·반입·복용을 권유하지 않으며, 제품명·성분·제형의 차이를 비교하기 위한 참고 정보만 제공한다.

| 구분 | 설계 결정 |
|---|---|
| 조회 대상 | openFDA NDC Directory의 미국(US) 유통 제품 |
| 성분 해석 순서 | `ingredient_en` → `atc_code` 기반 로컬 ATC 사전 → 기존 한글 성분 매핑 |
| 미국 통용명 보정 | INN/USAN 별칭 로컬 사전을 이용한 OR 검색 |
| 호출 시점 | `SCR-DETAIL-001`의 해외 제품 탭 최초 선택 시에만 lazy-load |
| 최대 반환 | 브랜드 제품 우선, 브랜드명·제형 기준 중복 제거 후 최대 12건 |
| 결과 없음 | 정상 응답(`available=true`)과 안내 문구를 반환 |
| 매핑·외부 조회 실패 | 해당 탭만 `available=false` 및 재시도 UI를 반환하며 다른 탭은 유지 |
| 안전 고지 | 국내 제품과 함량·제형·허가사항이 다를 수 있고, 반입·복용 전 의사·약사와 상담해야 함을 상시 표시 |

## 2. API 계약

`GET /api/drugs/{drugId}/overseas-products`는 `OverseasProductResponse`를 반환한다. 응답에는 약 식별자, 실제 검색에 사용한 영문 성분명, 가용 여부, 최대 12건의 미국 제품 정보, 안내 문구와 고지 문구를 포함한다.

> **해석 원칙:** 같은 주성분으로 검색된 미국 유통 제품은 국내 약과 동일한 제품이라는 뜻이 아니다. 복합제 여부, 함량, 제형, 투여경로, 허가사항은 제품마다 다를 수 있다.

## 3. 스키마와 매핑

Flyway V3에서 `drugs.atc_code VARCHAR(10)`과 조회 인덱스를 추가한다. 기존 데이터는 `ingredient_en` 또는 기존 한글 성분 매핑을 먼저 사용하므로, ATC 코드가 아직 비어 있어도 기존에 지원되는 성분의 해외 제품 조회는 가능하다. ATC 코드가 채워지는 경우에는 번들된 `atc-ingredient-en.csv`와 `inn-usan-alias.csv`가 더 넓은 성분명·미국 통용명 해석을 제공한다.

## 4. 리팩터링 범위

첨부 리팩터링 지침 중 현재 기능 추가와 직접 연관된 P1·P2를 함께 반영한다.

| 우선순위 | 반영 범위 |
|---|---|
| P1 | `ContraindicationPanel.vue`를 중복 경고·병용금기 섹션으로 분리 |
| P1 | `useDrugDetail.js`에서 부작용·중복 경고·병용금기·해외 제품 lazy-load 상태를 `useDrugSafety.js`로 분리 |
| P1 | ESLint·Prettier 설정 및 `lint`, `format`, `format:check` 명령 추가 |
| P2 | `SideEffectAliasMapper`로 국내/해외 이상반응 별칭 판정 책임 분리 |
| P2 | 해외 제품 파싱·성분 해석 단위 테스트 및 기존 전체 테스트 실행 |

DTO 전면 분리나 TypeScript 전환은 현재 규모에서 불필요한 변경이므로 이번 범위에서 제외한다.
