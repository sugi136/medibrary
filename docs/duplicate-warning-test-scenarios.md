# 동일 성분·효능군 중복 경고 검증 시나리오

## 1. 검증 대상과 전제 조건

검증 대상 화면은 `SCR-DETAIL-001`의 **함께 복용할 때 주의할 점** 탭이다. 동일 성분 중복은 로그인 사용자의 즐겨찾기 목록을 기준으로 하므로, 재현 시에는 테스트 계정으로 로그인한 뒤 두 의약품을 즐겨찾기에 등록해야 한다. 효능군 중복은 DUR 공개 API를 통해 현재 선택 의약품을 기준으로 조회하며, 로그인 여부와 무관하게 표시된다.

| 구분 | 기준 데이터 | 판정 방식 |
|---|---|---|
| 동일 성분 중복 | 현재 약과 즐겨찾기 약의 `ingredientEn` 일치 여부 | 일치하면 `SAME_INGREDIENT` 경고 반환 |
| 효능군 중복 | DUR `getEfcyDplctInfoList03` 조회 결과 | 반환 후보를 `SAME_EFFICACY_GROUP`으로 표시 |
| 병용금기 | 기존 DUR 병용금기 조회 | 기존 `CONTRAINDICATED`/`CAUTION` 목록 유지 |

## 4. 운영 재현 절차

1. [메디브러리 타이레놀 상세 페이지](https://medibrary-penguin16.vercel.app/drugs/202106092)에 접속한다.
2. **함께 먹으면 안 되는 약** 탭을 선택한다.
3. 비로그인 상태에서는 동일 성분 확인이 즐겨찾기 기반이라는 안내와 효능군·병용금기 결과를 확인한다.
4. `TC-DUP-001`을 재현하려면 로그인 후 아세트아미노펜 성분의 다른 제품을 즐겨찾기에 등록한 다음, 타이레놀 상세 페이지의 탭을 다시 연다.

> 이 기능은 복용을 자동으로 판정하거나 중단을 권고하지 않는다. 동일 성분·효능군 중복은 복약 점검을 위한 경고 정보이며, 실제 복용·병용 여부는 의사 또는 약사와 확인해야 한다.
